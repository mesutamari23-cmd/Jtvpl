# Xtream IPTV Player App (Android TV & Mobile)

تطبيق بث قنوات ومحتوى IPTV حديث وعصري يدعم سيرفرات **Xtream Codes API** ومصمم ليعمل بسلاسة على شاشات التلفزيون (Android TV / Fire TV) والهواتف الذكية.

## المميزات الرئيسية
- 📺 **دعم كامل لـ Xtream Codes API:** تسجيل دخول بسيط برابط السيرفر، اسم المستخدم، وكلمة المرور.
- 🎨 **واجهة زجاجية عصرية (Glassmorphism):** شاشة رئيسية مقسمة لـ (البث المباشر، الأفلام، المسلسلات).
- 📱📺 **متوافق مع التلفزيون والهواتف:** دعم كامل للتنقل بواسطة ريموت التلفزيون (D-Pad Focus) واللمس للهاتف.
- ⚽ **تقسيم منظم للقنوات:** دعم الفئات المخصصة (beIN Sports, MBC, OSN, News, French, etc.).
- ⚙️ **جاهز للرفع على GitHub:** يتضمن ملفات إعدادات مشروع Flutter جاهزة للبناء المباشر.

## كيفية الرفع والتثبيت عبر GitHub:
1. قم بفك الضغط عن هذا الملف.
2. قم بإنشاء Repo جديد على حسابك في GitHub.
3. ارفع كافة الملفات إلى المستودع (Repository).
4. لبناء ملف APK عبر أجهزة الحاسوب:
   ```bash
   flutter pub get
   flutter build apk --release
   ```
